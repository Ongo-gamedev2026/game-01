## 💬 가장 효과가 좋았던 프롬프트

> 💡 AI에게 보낸 문장을 **그대로** 붙여넣어요. 어떤 점이 좋았는지도 한 줄 적어 봐요.

```text
HTML, CSS, JavaScript를 사용해서 '카페 운영' 2D 웹게임을 만들어줘.   코딩 초보 고등학생도 이해할 수 있는 직관적이고 깔끔한 구조로 작성해줘.
HTML, CSS, JavaScript를 외부 파일, 서버, 라이브러리, 로그인, 외부 이미지 없이 하나의 HTML 파일에 모두 포함해줘.
화면 구성으로 게임 시작 화면, 게임 화면, 점수 및 제한시간 표시, 상점 모달, 레시피 보드, 게임 종료 화면, 다시 시작 버튼을 포함해줘.
디자인은 밝고 귀여운 파스텔톤 색상과 픽셀 감성의 아기자기한 2D 디자인, 이모지 캐릭터, 액체 출렁임 및 마블링 CSS 애니메이션을 적용해줘.
마우스 클릭으로 쉽게 조작할 수 있게 해줘.   제한시간은 120초(2분)로 설정해주고, 상점을 열었을 때는 게임 타이머가 일시정지되게 해줘.

게임 화면 한쪽에 현재 만들 수 있는 음료의 레시피 목록과 가격, 필요한 재료 조합을 항상 보여주는 레시피 보드를 만들고, 상점에서 새 레시피를 구매할 때마다 레시피 보드에 자동으로 추가되게 해줘.

음료 제작 시 색상이 단순히 static하게 쌓이는 것이 아니라, 재료 비율에 따라 평균 RGBA 색상이 계산되어 부드러운 linear-gradient와 Wave 파도, Swirl 마블링 효과로 자연스럽게 섞이도록 표현해줘. 얼음은 위에 떠 있는 애니메이션 효과를 부여해줘.

손님이 요구하는 인내심 게이지에 따라 서빙 보상을 다르게 책정해줘.
인내심이 70% 이상 남아있을 때는 빠른 서빙으로 정가의 150% 금액과 콤보 팁을 지급해줘.
인내심이 30%에서 70% 사이일 때는 보통 서빙으로 정가를 수령하게 해줘.
인내심이 30% 미만 남아있을 때는 느린 서빙으로 50% 감봉된 금액을 수령하게 해줘.
음료를 서빙할 때 획득한 금액과 속도 평가 메시지가 손님 위로 떠오르는 플로팅 애니메이션 팝업을 보여줘.

버는 돈으로 새 레시피(카페라떼, 딸기라떼, 말차샷라떼, 망고스무디, 유니콘 칵테일 등)를 해금할 수 있는 상점 버튼과 모달창을 만들어줘.
새로 해금된 레시피와 전용 재료는 손님 주문 목록 및 재료 선반에 동적으로 반영되게 해주고, 고급 레시피일수록 손님이 주문했을 때 버는 수익이 비약적으로 증가하도록 설정해줘.
```

**👍 좋았던 이유:** 음료 제작 과정과 서빙 속도, 상점 해금까지 카페 운영의 핵심 재미 요소들이 직관적이고 완성도 있게 반영되어서 좋았던거 습니다
