## 1️⃣ Gemini에게 보낸 게임 만들기 프롬프트

> **🎮 Gemini로 내 게임 만들기 → 3단계**에서 프롬프트를 복사하면 여기에 자동으로 들어가요.

```text
너는 고등학생과 함께 HTML 웹게임을 만드는 게임 개발자야.
맨 아래 [내 게임 기획서]는 내가 3주차에 정리한 게임 기획서야.
첨부한 이미지는 3주차에 만든 이 게임의 "스테이지 1" 화면 목업이야. 화면 배치, 색, 모양, 점수·버튼 위치는 이 목업을 최대한 따라 해.
이것을 바탕으로 "스테이지 1"을 실제로 플레이할 수 있는 웹게임으로 만들어 줘. Canvas에서 바로 실행해 볼 수 있게 만들어 줘.

[만드는 규칙]
- HTML 파일 하나에 HTML, CSS, JavaScript를 모두 넣어. 외부 이미지·소리 파일이나 라이브러리 없이 브라우저에서 바로 실행되게 해.
- 기획서의 5-1(시작할 때·플레이 중·클리어 조건·실패 조건), 5-2(등장하는 것들), 5-3(입력)을 하나도 빠뜨리지 말고 넣어.
- 화면 시점은 기획서의 화면 시점을 따라. 없으면 목업 이미지의 시점을 따라.
- 캐릭터와 물건은 도형, 이모지, Canvas 그리기로 단순하게 표현해.
- 기획서에 없는 기능(새 캐릭터, 스테이지 2, 상점, 업그레이드 등)은 넣지 마.
- 기획서에 숫자가 없는 것(속도, 시간, 개수 등)은 처음 하는 사람도 할 만한 값으로 정하고, 코드 맨 위에 "설정값"으로 모아 둬.
- 순서: 시작 화면(게임 제목, 조작법, 시작 버튼) → 게임 → 클리어 또는 게임오버 화면(결과, 다시 하기 버튼).
- 화면을 클릭하지 않아도 키보드가 바로 동작하게 하고, 방향키나 스페이스를 눌러도 페이지가 스크롤되지 않게 해.
- 코드 중요한 곳에 한국어 주석을 달아 줘.

[게임을 만든 다음 글로 알려 줘]
1. 기획서 반영 점검표: | 기획서 칸 | 게임에 넣은 방법 | ✅ 넣음 / 🔺 바꿈 / ❌ 못 넣음 |
2. 네가 정한 숫자: 기획서에 없어서 네가 정한 값(속도, 시간, 개수 등)과 코드 속 설정값 이름
3. 조작법
4. 처음 플레이할 때 꼭 확인해 볼 것 3가지

마지막에 "플레이해 보고 고치고 싶은 곳을 하나씩 말해 줘"라고 말해 줘.

[내 게임 기획서]
1. 한 문장 소개: 아기자기한 2D 공간에서 손님 주문에 맞춰 음료를 만들고, 서빙과 상점 해금으로 재미를 더한 귀여운 카페 경영 웹게임입니당
2. 타깃 플레이어: 나
3. 레퍼런스 게임:
   - 쿠킹 다이어리(Cooking Diary) (장르: 경영 타이쿤) → 참고하고 싶은 점: 제한 시간 안에 목표 금액 달성, 손님이 화나서 나가면 안 되는 규칙
   - 커피 토크(Coffee Talk) (장르: 시뮬레이션) → 참고하고 싶은 점: 재료를 넣을 때마다 색이 섞이는 낭만적인 시각적 느낌
4. 핵심 재미 요소: 손님의 주문에 따라 음료 만들기
5-1. 스테이지 1에서 일어나는 일:
   - 시작할 때: 시작하기 버튼을 눌러서 게임을 시작한다
   - 플레이 중: 재료를 조합해 음료를 만들어 서빙하고 돈을 번다
   - 클리어 조건: 120초가 지나 '영업 종료'가 되었을 때 정산하여 1000원 벌면 별 1개(기본 클리어), 2000원은 별 2개, 3000원은 별 3개
   - 실패 조건: 120초가 끝났는데 1000원(별 1개)을 못 벌었거나, 손님이 화내며 나가서 화면의 '하트(목숨)' 3개가 다 닳았을 때 즉시 게임 오버
5-2. 스테이지 1에 등장하는 것들:
   - 플레이어 → 갖고 있는 정보: 현재 소지금(돈), 제한시간(120초), 하트 3개(목숨) / 하는 행동·규칙: 재료 버튼을 눌러 음료를 만들고 손님에게 서빙한다.
   - 손님 → 갖고 있는 정보: 캐릭터 이모지, 원하는 음료 주문, 인내심 게이지 / 하는 행동·규칙: 화면에 나타나 음료를 주문하고, 시간에 따라 인내심이 줄어든다.
   - 음료 → 갖고 있는 정보: 담긴 재료 조합, 액체 색상 / 하는 행동·규칙: 재료를 넣을 때마다 색이 섞이고 양이 채워진다.
   - 상점 → 갖고 있는 정보: 해금 가능한 레시피 목록, 해금 가격 / 하는 행동·규칙: 돈을 사용해 새로운 레시피와 전용 재료를 해금한다.
   - 빈 컵 → 갖고 있는 정보: 담기는 재료 정보 / 하는 행동·규칙: 재료 버튼을 누르면 재료가 담긴다.
   - 쓰레기통 → 갖고 있는 정보: 버리기 기능 / 하는 행동·규칙: 버리기 버튼을 눌렀을 때 작용하여 컵을 비운다.
5-3. 입력 방식: 마우스
   - 재료 버튼 클릭 → 컵에 에스프레소, 우유, 얼음 등 원하는 재료를 넣는다
   - 서빙하기 버튼 클릭 → 만든 음료를 손님에게 제출하여 돈과 팁을 번다.
   - 버리기 버튼 클릭 → 잘못 만든 음료를 쏟아 버리고 컵을 비운다.
   - 상점 열기 / 구매 버튼 클릭 → 상점 창을 열고, 번 돈으로 새 레시피와 재료를 해금한다.
5-4. 화면 시점: 고정 한 화면 / 카페 경영 게임은 손님의 주문, 재료 버튼, 컵, 쓰레기통이 한눈에 다 들어와야 마우스로 빠르게 클릭할 수 있기 때문
6. 더 추가한 것:
   - 음료 기본 가격: 1000원(별 1개) 달성을 위한 음료 1잔의 기본 가격 설정 (예: 250원 등)
   - 나중에 할 것: '상점 열기 및 레시피 해금 초반 제외'는 스테이지 1에서는 미루고, 스테이지 1은 기본 재료 3개로 기초 뼈대 위주로 진행
```
